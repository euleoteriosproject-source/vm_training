# Vital Animations Free Pack — checklist de licença

Status: **não validado / não importado**.

Antes de usar o pacote:

- obter o pacote somente pelo canal oficial;
- guardar neste diretório uma cópia da EULA e a versão/data do pacote;
- confirmar explicitamente que a licença permite uso e redistribuição dos clips processados em um web app;
- registrar autor, fonte e texto de atribuição;
- executar `pnpm media:local --manifest ... --license-file ... --confirm-web-redistribution`.

O nome “Free Pack” não é tratado como autorização automática. Sem comprovação documental, nenhuma mídia é importada.
